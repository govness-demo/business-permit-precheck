# Business permit pre-check

Checks a business permit application for missing documents and eligibility before it is filed.

## Overview

An encoded version of the business permit checklist. An agent walks the applicant through each requirement, flags missing documents and explains the fee schedule before anything is submitted.

## Interfaces

Protocol: `other`. Languages: en, sw.
